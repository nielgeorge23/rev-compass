Engagement configuration

Per-client thresholds — what makes RevCompass reusable across health systems rather than hard-coded to one. Tagged items are human-in-the-loop (HITL) gates.

Auto-recommend threshold HITL
Confidence score above which a package is auto-recommended rather than routed to manual research.
Manual review threshold HITL
Below this confidence, a package always routes to the Manual Review Queue for human sign-off.
Supervisor override HITL
Requires a written justification, logged to the audit trail, to approve a package below the manual-review threshold.
Minimum cohort size
Claims below this count stay as standalone review items rather than forming a cohort.
Urgency lane window
Days before filing deadline at which a claim is scored standalone rather than waiting on its cohort. Filing deadline is never used to group claims into a cohort.
Appeal unit cost
Used in the expected-value calculation. Calibrate against this client's actual rework cost.
Cross-client fingerprint sharing
Pool de-identified payer behavior with other RevCompass clients on the same payers.
